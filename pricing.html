速率限制说明

Free 免费版（无 key） 60 requests / 分钟
Partner 合作方（slb_ key） 120 requests / 分钟
Pro 专业版（gtk_ key） 600 requests / 分钟

速率限制基于滑动窗口计算。超出限制时 API 返回 HTTP 429，响应头含 Retry-After 指示重试间隔。

如何开始

选择套餐

根据需求选择 Free / Partner / Pro。Free 无需注册直接使用；Partner 联系运营方洽谈；Pro 走虎皮椒支付。

获取 API Key

Free 无 key 直接调用；Partner 获发 slb_...；Pro 付款后获发 gtk_...（HMAC 签名，无状态可验证）。

调用 API

请求头添加 Authorization: Bearer <your_key>。生产端点 https://api.swarmlabs.tools。

数据自动同步

实体数据每日累积，搜索索引每日重建，OSS 注册表每日扫描。你的 key 独立，数据更新无需重连。

Quick Start 三行代码接入

# 1. 免费浏览领域（无 key）
curl -s https://api.swarmlabs.tools/v1/domains | jq '.sites[:5]'

# 2. Pro 语义搜索
curl -s -X POST https://api.swarmlabs.tools/v1/search/semantic \
  -H "Authorization: Bearer gtk_..." \
  -H "Content-Type: application/json" \
  -d '{"query": "reinforcement learning safety", "sites": ["ai-safety"]}'

# 3. Partner 全量数据（slb_ key）
curl -s -H "Authorization: Bearer slb_..." \
  https://swarm-labs-gateway.61960005.workers.dev/v1/entities

常见问题

免费额度用完怎么办？

Free tier 是 60 次/分钟（不是按天/月配额），正常使用不会触及。如果确实需要更高配额，升级 Pro 到 600/分钟。

数据是实时的吗？

实体数据每日累积（每小时批处理），搜索索引每日重建，OSS 注册表每日扫描。数据新鲜度见 /v1/domains 返回的 lastUpdated 字段。

数据覆盖哪些领域？

30 个科技主题子站：agent-ecosystem / agritech / ai-safety / ai4science / biomed-ai / brain-science / carbon-neutral / deep-sea-tech / embodied-ai / quantum-computing / robot-parts / semiconductor 等。完整列表见 /v1/domains。

数据源来自哪里？

arXiv / Semantic Scholar / Crossref / EuropePMC / Papers with Code / GitHub / HuggingFace。所有来源均为公开学术 / 开源数据。

Pro 买错了能退吗？

终身授权 ¥199 一次付费，不退不换。年订阅 ¥39.9 到期后不续费自动降级为 Free。付款前请确认套餐。

国内网络能用吗？

生产端点 api.swarmlabs.tools 走 Cloudflare Worker，海外可用；国内网络需自建 CDN 回源或走代理。Worker 直连兜底端点 https://genetech-api-guard.61960005.workers.dev。

数据能用于训练吗？

可以。数据来自公开学术 / 开源来源，MIT 许可证。消费者自行负责下游合规（如 GDPR、CC 协议等）。
