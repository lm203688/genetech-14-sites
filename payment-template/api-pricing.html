速率限制说明

免费版（匿名 / Free Tier） 30 requests/hour
专业版（Pro Tier） 60 requests/hour
终身版（Lifetime Tier） 120 requests/hour

速率限制基于滑动窗口计算。超出限制时，API 将返回 HTTP 429 状态码。 每日配额在 UTC 00:00 重置。

支付完成后收到 License Key，在积分页面输入 API Key 和 License Key 完成兑换。
