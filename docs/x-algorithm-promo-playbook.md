# 借鉴 X（Twitter）开源推荐算法 · 14 站推广打法手册

> 核心思路：X 在 2023 年开源了推荐系统的**排序服务**代码（`twitter/the-algorithm`），把排名信号和权重亮了出来。
> 这些信号揭示的是**现代信息流排名的通用原理**——小红书 / 知乎 / 公众号 / 掘金 / B站 乃至我们自己的 GEO 内容引擎，feed 机制本质同源。
> 所以本手册**不直接依赖你能登录 X**（你在中国大陆，X 无法直连），而是把 X 算法当"设计参考"，
> 分成两条落地轨道：Track A（你当下就能在可达平台做）、Track B（若你有海外通道/合伙人时的 X 直发稿）。

---

## 0. 一句话结论（客观版）

X 算法奖励的排序是：**真实互动（尤其回复）> 早期势能 > 媒体 > 社区对齐 > 作者信誉**，并对垃圾行为重罚。
把它翻译成我们的推广：**每篇内容必须在前 30 分钟拿到第一批互动、必带图、末尾抛一个能诱发评论的真问题、精准投对圈子、把互动转化为许可证 CTA。**
注意一个诚实边界：X 算法服务的目标是"让用户留在 X 上"；我们的目标是"引流到 license + 被 AI 引述"。
所以**不能为互动而互动**——每个钩子都要把人导向我们的 47k 实体数据集 / `npx @genetech/data-mcp` / 买断页，否则互动是虚胖。

## 1. X 开源算法到底公开了什么（已核实，截至 2026-08）

四阶段流水线：

1. **候选生成（~1500 条）**：约 50% 来自你的社交图（RealGraph 算互动概率），50% 来自域外（SimClusters 社区嵌入 / GraphJet 图遍历 / UTEG）。
2. **特征 hydration（~6000 个特征）**：预测互动、内容质量、社交图信号。
3. **排序**：Light Ranker 粗排 → **Heavy Ranker（4800 万参数神经网络）** 精排，多任务预测 点赞/转推/回复/资料点击/停留 的概率。
4. **过滤与混合**：多样性（同一作者不过量）、质量阈值、混广告。

### 1.1 线性打分公式（核心，`LinearScopingFunction`）

```
finalScore = BASE
           + retweetWeight × log2(retweets)
           + favWeight     × log2(likes)
           + replyWeight  × log2(replies)
           + reputationWeight × userReputation
           + textScoreWeight   × contentQuality
           + boostFactors
           − penalties
```

**公开泄露的权重常量（2023 开源代码，相对大小稳定、2025 多篇分析印证）**：
- 回复（reply）≈ **13.5**，转推（retweet）≈ **1.0**，点赞（like）≈ **0.5**。
- **作者的回复**（PredictedReplyEngagedByAuthorScoreFeature）权重更高 → 自己下场接话极值钱。
- 含义：**1 条回复 ≈ 27 个赞的权重**。评论是分发的第一杠杆。

**log2 缩放（早期势能）**：第 1 次转推贡献 100%，第 2 次 +58%，第 4 次 +32%，第 8 次 +17%。
→ 冷启动前 10 分钟 / 第 1 小时的决定性，远大于总量。

### 1.2 直接 boost（加权）
- 热门话题 `tweetHasTrendBoost`
- 媒体（图/视频）`tweetHasMediaUrlBoost`
- 新闻链接 `tweetHasNewsUrlBoost`
- 认证作者 / 蓝标 `tweetFromVerifiedAccountBoost`

### 1.3 重罚（扼杀触达）
- 举报：权重高达 **−20,000**（一条就能毁掉一条推文）
- "不感兴趣"：−1,000 量级
- 静音 / 拉黑 / 看了取关 → 强负反馈
- **超过 2–3 个 hashtag → 降权**；垃圾模式 → 过滤；全大写"喊叫" → 质量惩罚；冒犯内容 → 影子禁言

### 1.4 作者信誉（Tweepcred，PageRank 式）
- 认证账户：固定 100 分
- 账户年龄因子：`min(1.0, log(1 + age/15))`（30 天后满收益）
- 设备权重：用移动端 App +50%
- **关注/粉丝比惩罚**：关注 >500 且 比例 >0.6 → `score / exp(5 × (ratio − 0.6))`，严厉。保持比例 < 0.6。
- SimClusters：14.5 万个兴趣社区，每 3 周刷新；域外发现的主通道 = 内容"嵌入"到对的社区。

## 2. 信号 → 我们打法的映射表（核心）

| X 已验证信号 | 机制 / 权重 | 对我们的含义 | Track A（中文平台 / 自有 GEO） | Track B（X 直发） |
|---|---|---|---|---|
| **回复（尤其作者自回）** | 最高（reply≈13.5 vs like≈0.5） | 评论/互动是分发第一杠杆 | 每篇末尾抛**一个真问题**诱发评论；在知乎/公众号主动回评 | 帖文用"争议但真实"的判断 + 提问钩子，自回前排 |
| **早期互动速度（log2）** | 前 10 分钟/1 小时决定性 | 冷启动窗口必须有人接 | 发布后自己/种子号立即互动；GEO 文发布即提交索引/GSC | 海外伙伴发帖后 30 分钟内互推 |
| **媒体（图/视频）** | 直接 boost | 纯文字没流量 | 每篇配数据图/信息图（47k 实体可做卡片） | 必带图，视频前 3 秒放亮点 |
| **停留时长（详情>15s / 资料>20s）** | 高权重 | 长文/干货更易被推 | 写"收藏级"深度长文（表格/列表/分节） | 长推文 + thread 线索帖 |
| **社区对齐（SimClusters）** | 域外发现主通道 | 投对圈子 > 广撒网 | 精准投 生信/AI4S/计算生物 社群，不泛科技 | 打对社区标签，进相关 cluster |
| **作者信誉（Tweepcred）** | 基准分 | 账号权威影响触达 | 养号：完整资料、稳定更新、不刷粉 | 用有历史的号/蓝标；关注比 < 0.6 |
| **转发（已关注者转）** | 网络效应加权 | 核心粉丝放大 | 建一个铁粉种子群定期放大 | 已有 follower 转推权重更高 |
| **热点 / 新闻链接** | 直接 boost | 蹭热点提权重 | 结合实时科研新闻写 | 绑当下 AI4S 热点 |
| **惩罚：举报/不感兴趣/取关/堆标签/全大写/标题党** | −20000 ~ 降权 | 一次作死 '' 全完 | 不标题党、标签 ≤2–3、不大写喊叫 | 同理；避免 spam 自动化 |

## 3. Track A：你当下就能做的（不依赖 X 直连）

### 3.1 把"评论钩子"写进每篇内容（最重要）
X 告诉我们回复权重是点赞的 ~27 倍。在小红书/知乎/公众号/掘金同理——**能诱发评论的内容被推得更狠**。
做法：每篇末尾留一个**真问题 + 软 CTA**，把互动导向转化：
> "你做 XX 方向的研究，最缺哪类结构化数据？评论区告诉我——我们 47k 条实体里有对应策展域，可 `npx -y @genetech/data-mcp` 直接接。"

### 3.2 冷启动 30 分钟窗口
发布后立刻自己做第一波动作（点赞/收藏/转发到自己），若有铁粉群同步推。GEO 文发布即：提交 sitemap / GSC / IndexNow，让 AI 引擎尽早"拾取"（类比 X 的 early-pickup）。

### 3.3 媒体必须带
我们 47k 实体是天然素材：每月做 2–3 张"数据卡片"（某域实体增长曲线、跨域桥接热力图），配每篇推文。无图不发车。

### 3.4 投对圈子（SimClusters 类比）
别发"泛科技"。锁定：生信/计算生物/AI4S/材料基因/合成生物 等垂直社群。圈外曝光再多，不如圈内一次精准触达。

### 3.5 养号信誉（Tweepcred 类比）
各平台用**稳定、完整、垂直**的人设号；不买粉、不互刷；保持关注/粉丝比健康。权威号发同样内容触达高数倍。

### 3.6 躲惩罚
标题党、堆标签（>2–3 个）、全大写喊叫、spam 自动化——这些在中文平台一样被降权。质量 > 数量。

### 3.7 把"停留时长"当 KPI
写"收藏级"长文（表格 + 分节 + 列表 + 数据），让人愿意停留/截图/转发。我们的 GEO 权威文（bio×AI、基因编辑 2.0）就是这个形态，直接改写成各平台版本。

## 4. Track B：若你有海外 X 通道（合伙人 / 合规节点）

> 仅当你能合规触达 X 时执行。下面给可复制模板（英文，面向 AI4S / bio×AI 受众）。

**模板 1 — 回复钩子 + 媒体**
```
We just cross-checked 47k structured research entities across AI4S / genomics / synthetic bio.
The pattern that surprised us: [ONE concrete finding].
What's the biggest gap in your research data stack? 👇 (we'll point you to the curated domain)
— Unified knowledge engine, `npx -y @genetech/data-mcp`
[attach data-card image]
```

**模板 2 — 争议但真实 + thread**
```
Unpopular take: most "AI for Science" datasets are toys. Real leverage is *structured, citable, cross-domain* entities.
A thread on what actually moved the needle in 2025–2026 🧵 [media]
1/ AlphaFold 3 shifted structure prediction from single-chain to complex-level…
…
```

**发布纪律（X 算法版）**：
- 发帖后 30 分钟内自回前排评论、回复他人 → 触发 author-reply 超高权重。
- 用有历史的号 / 蓝标；关注比 < 0.6；移动端发。
- 绑当下 AI4S 热点（如某新论文/会议）拿 trend boost。
- 图片/视频必带；标签 ≤2–3；不大写喊叫；不 spam 自动化。

## 5. 织进每周自动化（内容自检清单）

每周一自动化生成的 GEO 文，必须默认带以下"高排名结构"（已写入自动化 prompt）：
1. **钩子问题**：末尾一句能诱发评论的真问题（回复=最高权重信号）。
2. **媒体**：至少 1 张图/图表（媒体 boost；无图不发车）。
3. **停留友好**：结构化长文（表格/列表/分节），收藏级深度。
4. **社区对齐关键词**：精准垂直词（AI4S / 生信 / 计算生物…），不泛化。
5. **转化 CTA**：末段指向 license / `npx @genetech/data-mcp`（把互动变转化）。
6. **避罚**：不堆标签、不大写喊叫、不标题党、不 spam。

## 6. 诚实边界（必读）

- **X 算法会变**，且只服务 X 自身商业目标；本手册借鉴的是"稳定通用原理"，不是钻漏洞。
- **你在中国无法直接登录 X**：Track B 需海外通道/合伙人；否则只做 Track A（已覆盖主价值）。
- **不为互动而互动**：评论若带不来潜在买家/被引述，就是虚胖。每个钩子必须回指数据集/许可证。
- **质量 > 数量**：X 与所有中文平台都对垃圾行为重罚，慢即是快。
