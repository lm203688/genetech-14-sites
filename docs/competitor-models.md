## 0. 一句话结论

竞品里**真正能用上**的，不是某个产品的完整模式，而是三类「可插拔机制」：

1. **Perplexity 的「开放数据即获客 + 订阅优先 + 出版商计划」** → 对应我们的 免费层 GEO + ¥9.9/¥199 买断 + 数据授权给 AI 公司。
2. **MCP 市场的「API-key 漏斗 / 免费增值 + 目录发现」** → 对应我们的 `npx @genetech/data-mcp` 分发 + 目录认领。
3. **小鹅通的「0 抽佣 SaaS + 私域 + 微信生态」** → 对应我们的 虎皮椒买断 + 私域复购。

⚠️ 明确**不要抄**的：MCP 市场的高抽成/纯订阅制（与开源协议冲突、与国内买断习惯冲突）；AI4Science 的「自有管线赌单药」模式（风险极高、非我们定位）。

## 1. AI 答案引擎：Perplexity / 秘塔AI（Metaso）

### 1.1 Perplexity（2026 数据）
- **定价**：Freemium；Pro $20/月、Max $200/月、Enterprise $40–325/seat/月；Sonar API 按 token 计费。
- **变现演化**：2026-02 从「广告优先」转向「订阅优先」，转型后数周收入 +50%。
- **规模**：ARR 从 ~$200M（2025）冲到 $500M（2026-04）；估值 $21–22.6B（2026-01）。
- **分发**：Samsung Galaxy S26 操作系统级「Hey Plex」入口（2026）；曾与 Snap 签 $400M 合作（已结束）。
- **模型**：「答案引擎 + 引用溯源 + 模型自选 + 出版商计划（Comet Plus $5/月，拨 $42.5M 分给出版商）」。

### 1.2 秘塔AI（Metaso，国内对标）
- **定价**：免费（100 次/日）；会员 ~¥39/月 或 ¥92/年；API ¥0.03/次；企业私有部署。
- **差异化**：中文垂直深度（学术/法律）、「小模型+大模型」+ Agentic Search；付费转化率约 8%（AI 工具里偏高）。

### 1.3 对 GeneTech 的可借鉴性
- ✓ **「开放数据即获客」机制**：Perplexity 的出版商计划本质是「用引用换分发」。我们的 `llms.txt` + `Dataset` JSON-LD + 全站开放数据，正是「让 AI 引擎免费引用我们」的物理基础 → 直接对齐，且边际成本≈0。
- ✓ **「订阅优先」而非「广告优先」**：验证了我们「免费层获客 + 买断/订阅转化」而非「靠广告」的方向正确。
- △ **出版商/分成计划**：可改造为「数据授权给 AI 公司」（$20万–500万/年，见 growth-strategy §9.1）——这是比 Perplexity 出版商分成更高客单的 B 端变现。
- ✗ **OS 级预装/巨额品牌合作**：我们体量不够，不抄；但「在 AI 答案里被引用」这个轻量分发逻辑可抄（GEO）。
- ✗ **纯订阅 $20/月**：国内用户对月费+信用卡有摩擦，**我们用一次性买断（¥9.9/¥199）替代**——这是秘塔用「年费 ¥92」验证过的「低价年付/买断」国内习惯，比 Perplexity 的月订阅更适配。

## 2. MCP 市场 / 目录：Glama / Smithery / MCPize / Apify / Nevermined

### 2.1 代表玩家与数据
- **Glama**：71,000+ servers；质量策展 + 安全扫描 + 85 分类；**创作者 0% 分成（平台全拿）**；靠订阅/广告变现。
- **Smithery**：14,240+ servers；$30/月；创作者 0% 分成。
- **MCPize**：创作者 **85% 分成**（Stripe 结算）。
- **Apify**：创作者 **80% 分成**，$1.4M/月 派发。
- **Nevermined**：每笔交易 1% 微支付（x402 USDC）。
- **mcp.so**：免费，无变现。

### 2.2 行业真相
- 4 类变现：订阅分层（$49/$299/$999）、按量（$0.001/次）、API-key 漏斗转 SaaS（Bright Data/Exa/Tavily）、免费增值。
- **只有 ~5% 的 12,000 个 server 真正赚钱**。核心洞察：**MCP 协议本身趋于免费（开放协议），差异化在「数据/逻辑」而非「协议」**。

### 2.3 对 GeneTech 的可借鉴性
- ✓ **「API-key 漏斗 / 免费增值」**：我们的 `npx -y @genetech/data-mcp` 就是免费发现层，Pro 密钥（HMAC 已在 api-guard 就绪）是漏斗出口 → 完全对齐。
- ✓ **「目录发现」**：Glama/Smithery/mcp.so/PulseMCP 认领（growth-materials §A）是低成本分发，必做。
- △ **分成比例**：我们不做「市场抽成」（我们是自有产品不是平台），但 Apify/MCPize 的高分成启示——**对生态合作伙伴（如 Coze bot 开发者、高校实验室）可搞收入分成**，激励他们帮我们分发。
- ✗ **Glama/Smithery 的「0% 给创作者 + 平台全拿」订阅制**：不适合我们——我们是内容/数据生产者自己卖，不是二道贩子；且 MCP 本就开放，靠「锁协议抽成」走不通（行业只有 5% 赚钱已证明）。
- ✗ **Nevermined 的微支付**：廉价查询按次收不值（50 次/天≈$15/月），我们早已判定 MCP 当分发层而非收费层。

## 3. 知识付费 SaaS：小鹅通 / 知识星球 / 得到

### 3.1 代表玩家
- **小鹅通**：SaaS 年费 ¥6,800 / 12,800 / 25,800；**配额内 0–2% 手续费、配额内 100% 给创作者**；强私域 + 微信生态。
- **知识星球**：个人 20% / 企业 5% 佣金。
- **得到/综合平台**：抽成 30–50%，私域弱。

### 3.2 对 GeneTech 的可借鉴性
- ✓ **「0 抽佣 + 年费 SaaS + 私域」是创作者最友好模型** → 映射到我们的 **虎皮椒一次性买断（无月费/无抽佣平台）** + 微信生态复购。我们比小鹅通更激进：连 SaaS 年费都不收，只收一次性密钥费。
- ✓ **私域复购**：知识星球/小鹅通的「社群+内容续费」逻辑 → 我们可做「终身版用户社群 + 新域上新通知」提升 LTV。
- △ **阶梯 SaaS 年费**：我们的 ¥9.9/¥39.9/¥199 买断已覆盖低门槛；**企业版（¥1999–9999/年 私有部署）对应小鹅通的高阶 SaaS 档**。

## 4. AI4Science 公司：Schrödinger / Recursion / Insilico / 晶泰

### 4.1 代表玩家与数据（2025 财报/进展）
- **Schrödinger**：2025 营收 $255.9M（+23.3%）；软件 $199.5M（占 78%，毛利率 74%）→ **软件授权是利润主力**。
- **Recursion**：2025 营收 $74.7M，净亏 $645M；NVIDIA 于 Q4'25 退出；削减管线 → **自有管线赌单药风险高**。
- **Insilico（英矽智能）**：BD 交易（Sanofi/Roche 首付 $134M）；Rentosertib 进 III 期，首个「AI 发现靶点+药物」。
- **晶泰科技**：2025 盈利（量子+AI+机器人）。

### 4.2 三条路径
1. **CRO 服务（卖人力）** → 天花板低。
2. **AI SaaS 授权（卖软件）** → 天花板中等，但可复制、毛利高（Schrödinger 印证）。
3. **AI+Biotech 自有管线（卖药）** → 价值最高（首付+里程碑+分成），但风险最高（Recursion 印证）。

### 4.3 对 GeneTech 的可借鉴性
- ✓ **「卖水人」模型（软件/平台授权，而非赌单药）**：Schrödinger 78% 软件收入、74% 毛利，是我们要走的路 → 映射到 **企业数据授权（$20万–500万/年）+ MCP/API 授权**，而非自己下场做药。
- ✓ **BD 交易的首付+里程碑+分成**：我们未来做「数据独占授权」时可套用此结构（growth-strategy §9.1）。
- ✗ **自有管线赌单药**：非我们定位、风险不可控，明确不抄（Recursion 教训）。
- △ **晶泰「盈利靠平台化（量子+AI+机器人）」**：启示我们「把数据引擎做成平台而非一次性交付」，与「持续扩量 + MCP 分发」一致。

## 5. AI 编程工具：Cursor / Replit

### 5.1 代表玩家
- **Cursor**：Pro $20/月、Ultra $200/月、Teams $40/seat。
- **Replit**：按「effort」credits 计费（$0.06–$1/任务）。
- 2025 共同趋势：**从席位订阅转向「按工作量/token 计费」**。

### 5.2 对 GeneTech 的可借鉴性
- ✓ **透明用量 credits + 可预期档位**：我们的「配额制密钥（100/500/无限）」已是同类思路；api-guard 的 PRO_SECRET/HMAC 已就绪，可支撑「按调用量计费」未来扩展。
- △ **从席位费到用量费**：若企业版做「API 调用量阶梯」，可参考 Replit effort 模型；但当前以买断为主、更适配国内。

## 7. 与现有商业架构的对应（呼应 growth-strategy §9.3）

```
免费层(开放数据+GEO获客) ─┐
Pro 买断(¥9.9/¥39.9/¥199 HMAC配额) ─┤→ MCP 分发层   ← Perplexity/秘塔/MCP市场机制
企业版(¥1999–9999/年 私有部署) ─┤
数据授权($20万–500万/年 给AI公司) ─┘  ← Schrödinger 卖水人 + Perplexity 出版商分成改造
```

**结论**：我们现有四层架构，已经「有机整合」了上述竞品中最适配的三类机制；竞品解析的价值在于**确认方向正确 + 指出高客单杠杆（数据授权）+ 划清不应抄的雷区（平台抽成、自有管线赌单药）**。

## 8. 风险与边界

- 竞品数据多为 2026 年一手调研、近似值，作战略参考非财务承诺。
- 「可借鉴」≠「照搬」：MCP 市场抽成、纯月订阅、自有管线三件事在本项目明确不可行（已论证）。
- 所有外部数据授权/企业版商务均需用户亲自谈客户、走合同——AI 只备料，不替用户签约。
