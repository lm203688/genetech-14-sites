## 3. 技术计量交接（api-guard 就绪，待用户部署）

> 代码侧已在 `api-guard/` 就绪（Pro HMAC + 配额）；以下为"把 L2 企业授权变成可计费产品"的交接清单。

- [ ] `unified-license/worker.js` 或 `api-guard/` 新增 **企业 API 密钥 tier**（区分 L1 个人配额与 L2 企业计量）
- [ ] 计量维度：`调用次数` + `返回实体域数` + `是否原始字段`（对应三档权益）
- [ ] KV 计费：按 `license_key → {tier, used, quota, renew_at}` 记录；超额走 `return_url` 引导增购
- [ ] 企业独享（旗舰版）：在 `state/` 或 KV 标记 `exclusive_domain`，CI 扩量时对该域打"已授权"标签，避免同年重复授权竞品
- [ ] 文档：`llms.txt` 已含引用授权声明；企业合同时附"数据来源与合规"附录（OpenAlex/arXiv/PubMed 等 CC 协议）

> 注意：**定价用档位包，不用纯按 token 计费**（避 Cursor 毛利陷阱）。我们数据第一方、无第三方推理成本，毛利结构优于秘塔。

## 4. 谈判结构（首付 + 里程碑 + 分成，晶泰/Schrödinger 验证）

旗舰/独占版建议采用"卖水人 + BD 交易"混合结构：

| 阶段 | 收项 | 说明 |
|---|---|---|
| 签约 | **首付 30–50%**（如 ¥300 万档付 ¥90–150 万） | 覆盖数据整理与对接成本 |
| 交付 | **里程碑款**（数据集交付/API 上线节点） | 分 2–3 期 |
| 运营 | **年费续费**（标准/专业版同此） | 可持续收入 |
| 增值 | **销售分成**（若客户用数据产生产品收入） | 晶泰"联合开发+里程碑"同构，可选 |

> 谈判底线：独占域的年费不得低于专业版 3 倍；非独占标准/专业版不接受"按效果付费"（保护现金流）。

## 5. 风险与边界
- 所有报价为**建议起点**，最终以用户与客户合同为准；AI 不替用户签约。
- 数据合规：实体来自开放学术源（OpenAlex/arXiv/PubMed/Crossref 等），授权时附来源协议附录，避免权属争议。
- 企业路由与密钥部署依赖用户本机 `wrangler secret` 与 Cloudflare 账户（沙箱无法代部署）。
- 与"个人买断"不冲突：L2 是企业 B 端授权，L1 是个人 C 端，渠道分立。
