## 0. 一句话结论（修正后）

**真正赚钱的竞品，共同逻辑是"卖访问权/基础设施，不赌单点结果"——但"已获利"要分两层看：**
- **干净净盈利**：仅 **晶泰科技**（2025 经调整净利 ¥2.58 亿，且 IFRS 年内利润也转正 ¥1.35 亿）、**秘塔**（创始人口径 2025 盈利，待审计确认）。
- **仅"经调整/分部"盈利、报表仍亏**：Schrödinger（软件毛利 74% 但公司 2025 净亏 $1.03 亿）、小鹅通（经调整净利破亿但 2025 IFRS 净亏 ¥6395 万）。

**我们的主逻辑（卖水人）在晶泰身上被完整验证**：它靠"平台授权 + 联合开发 + 里程碑 + 销售分成"首次盈利，且数据飞轮（AI 预测—机器人执行—数据反哺）正是我们"数据库持续扩张"的同构。Schrödinger 的软件高毛利也印证"授权数据/软件"是最高毛利引擎——但它 2025 仍净亏、且正经历管线挫败，说明**卖水人也要熬过投入期**。

## 2. 四条获利逻辑 → 本项目映射与待改项

### 逻辑 A：卖水人（晶泰 ✅净盈利 / Schrödinger 软件高毛利）
- **竞品证据**：晶泰"平台授权+里程碑+分成"驱动首次盈利（复购率>75%、17/20 大药企）；Schrödinger 软件毛利 74%、占营收 78%。
- **映射到我们**：企业版（私有部署）+ **企业数据授权（$20万–500万/年）+ MCP/API 授权**。
- **要改什么（P0）**：把"企业数据授权"升级为一号利润工程——报价单/BD 模板/技术计量已备（enterprise-data-license-kit.md）。
- **风险提醒（来自 Schrödinger）**：卖水人也要熬投入期，Schrödinger 熬到第 10 年仍净亏、且 2025 因 SGR-2921（CDC7/AML 抑制剂）致 2 名患者死亡暂停管线、裁员 ~60 人（~7%）降本 $3000 万/年。我们的优势是**数据第一方、无临床风险、无重资产**，护城河更轻。

### 逻辑 B：收入随客户增长（小鹅通 共生）
- **竞品证据**：小鹅通"订阅 + 云消耗 + 交易费"，**NRR 117.5%**，收入随客户业务放大（即便 IFRS 仍亏，经调整已盈利）。
- **映射到我们**：现在只有"一次性买断"，收入不随客户用量增长。
- **要改什么（P1）**：买断之上叠加**用量/授权层**——MCP 计量 API 档（api-guard 已支持 HMAC+配额）、企业按调用量/域数阶梯；定价用"档位包"而非纯按 token（避 Cursor 毛利陷阱）。

### 逻辑 C：免费获客 + 严控边际成本（秘塔）
- **竞品证据**：秘塔免费层获客、会员/API 转化、自训模型+智算中心把成本压住才盈利（据股东傅盛透露 2025 盈利）。
- **映射到我们**：免费 GEO（llms.txt/JSON-LD）+ 每周 GEO 文 = 获客漏斗已建；数据第一方，**边际成本≈0**，结构性优于秘塔（秘塔仍要养模型/算力）。
- **要改什么（P2）**：强化"答案被 AI 引用 → 落地 license 页 → 转化"CTA 闭环；MCP 目录认领（Glama/Smithery）待用户认领。**护城河铁律：永不租第三方模型按次计费**（我们无此成本，保持；Cursor 的负毛利正是反面教材）。

### 逻辑 D：私域高 LTV 社群（知识星球 洪灏样本 / 小鹅通）
- **竞品证据**：洪灏星球 ¥899/年 × 1.1 万 = 约 ¥989 万流水（6 周）；小鹅通私域 NRR 114%+。
- **映射到我们**：买断是一次性，LTV 天花板低。
- **要改什么（P1）**：新增"前沿数据内参"年费社群（¥299/年档），把买断用户沉淀为续费社群。

## 3. 落到四层架构的提升动作（优先级）

```
免费层(开放数据+GEO获客) ─┐
Pro 买断(¥9.9/¥39.9/¥199) ─┤→ MCP 分发层（获客漏斗，逻辑C）
企业数据授权($20万–500万/年) ─┤→ 卖水人主引擎（逻辑A，P0）
用量/授权叠加层(MCP计量API档) ─┤→ 收入随客户增长（逻辑B，P1）
私域年费社群(¥299/年) ─┘→ 抬 LTV（逻辑D，P1）
```

| 优先级 | 动作 | 对应逻辑 | AI 已做/能做 | 用户必须做 |
|---|---|---|---|---|
| **P0** | 企业数据授权报价单 + BD 邮件 + 技术计量交接 | A 卖水人 | `enterprise-data-license-kit.md` | 谈客户、走合同、设 api-guard 密钥与计费 KV |

| **P1** | 买断之上叠加 MCP 计量 API 档 | B 共生增长 | 计量档位定义已备 | 部署 api-guard 企业路由、配置配额 |

## 4. 明确"不抄"清单（带理由，已核实）

- ✗ **Recursion 赌单药 / 自有管线**：NVIDIA 2025 Q4 清仓、合并后仍季亏 >$1 亿 → 我们定位数据/平台方，不下场赌结果。
- ✗ **Cursor 纯按 token 计费 / 租模型**：2025 负毛利 -30%，靠自研模型才在 2026 初企业端勉强转正 → 我们只用档位包，且数据第一方无推理成本，天然规避。
- ✗ **Glama/Smithery 0% 给创作者 + 平台抽成**：仅 5% server 赚钱 → 自有产品自销，不做二道贩子平台。
- ✗ **Perplexity 广告模型**：未盈利、靠订阅转型才增收 → 坚持"免费层获客 + 买断/授权转化"，不靠广告。

## 6. 风险与边界（诚实标注）
- **"已获利"要分层**：干净净盈利仅晶泰、秘塔（创始人口径）；Schrödinger/小鹅通为经调整盈利、报表仍亏。引用时勿夸大。
