## 2. 四条获利逻辑 → 本项目映射与待改项

### 逻辑 A：卖水人（Schrödinger / 晶泰）
- **竞品证据**：Schrödinger 软件毛利 74%、占营收 78%；晶泰"平台授权+里程碑"驱动首次盈利。
- **映射到我们**：企业版（私有部署）+ **企业数据授权（$20万–500万/年）+ MCP/API 授权**。
- **要改什么（P0）**：把"企业数据授权"从 growth-strategy §9.1 的待办，升级为**一号利润工程**——出报价单、BD 模板、技术计量（api-guard HMAC 已就绪）。详见 `enterprise-data-license-kit.md`。

### 逻辑 B：收入随客户增长（小鹅通 共生）
- **竞品证据**：小鹅通"订阅 + 云消耗 + 交易费"，NRR 114–128%，收入随客户业务放大。
- **映射到我们**：现在只有"一次性买断"，收入不随客户用量增长。
- **要改什么（P1）**：在买断之上叠加**用量/授权层**——MCP 计量 API 档（api-guard 已支持 HMAC+配额）、企业按调用量/域数阶梯。但**定价用"档位包"而非纯按 token**（避 Cursor 毛利陷阱）。

### 逻辑 C：免费获客 + 严控边际成本（秘塔）
- **竞品证据**：秘塔免费层获客、会员/API 转化、自训模型把成本压住才盈利。
- **映射到我们**：免费 GEO（llms.txt/JSON-LD）+ 每周 GEO 文自动化 = 获客漏斗已建；数据第一方，**边际成本≈0**，比秘塔更优。
- **要改什么（P2）**：强化"答案被 AI 引用 → 落地 license 页 → 转化"的 CTA 闭环；MCP 目录认领（Glama/Smithery）待用户认领。**护城河铁律：永不租第三方模型按次计费**（我们无此成本，保持）。

### 逻辑 D：私域高 LTV 社群（知识星球 / 小鹅通）
- **竞品证据**：知识星球 ¥899/年强 LTV；小鹅通私域 NRR 114%+。
- **映射到我们**：买断是一次性，LTV 天花板低。
- **要改什么（P1）**：新增"前沿数据内参"年费社群（¥299/年档），把买断用户沉淀为续费社群，发周报/季度展望/上新提醒。

## 4. 明确"不抄"清单（带理由）

- ✗ **Recursion 赌单药 / 自有管线**：净亏 $645M、NVIDIA 退出 → 我们定位是数据/平台方，不下场赌结果。
- ✗ **Cursor 纯按 token 计费**：毛利长期为负（租前沿模型）→ 我们只用"档位包"定价，且数据第一方无推理成本，天然规避。
- ✗ **Glama/Smithery 0% 给创作者 + 平台抽成**：协议趋免费、仅 5% server 赚钱 → 我们是自有产品自销，不做二道贩子平台。
- ✗ **Perplexity 广告模型**：未盈利、靠订阅转型才增收 → 我们坚持"免费层获客 + 买断/授权转化"，不靠广告。
