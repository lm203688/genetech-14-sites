## 3. 行业专家视角（AI4S / MCP / GEO 从业者）

### 3.1 市场需求（技术趋势）
- **Agent 原生 + MCP 分发**已是明确方向（Scite MCP 2026、Glama/Smithery 生态）。
- **RAG-ready 结构化语料**（JSONL/Parquet + 数据字典 + provenance）是 AI 公司真实采购物，非原始 PDF。
- **垂直做深**优于全科做浅（Elicit 偏生物医学/社科、Consensus 非二元问题乏力）。

### 3.2 商业模式（生态位）
- 我们是 AI4S 的**「卖水人」**：卖软件/数据授权，不赌单药管线。→ 对齐 Schrödinger（软件 78% 营收、74% 毛利）、晶泰（平台授权+里程碑）。
- **明确不抄**：Recursion（自有管线赌单药，净亏 $645M、NVIDIA 退出）；Perplexity（未盈利、靠融资撑 ARR）；Cursor（租模型致负毛利）。

### 3.3 建议提升（技术/合规风险）
1. **数据质量即产品**：跨源去重率、摘要缺失率、溯源 URL 完整度必须持续监控（给 §4 健康巡检的输入）。
2. **增量更新**：当前以插入为主，应加「按 DOI 刷新」避免陈旧（growth-strategy §4.3 已提，未落地）。
3. **合规红线**：OpenAlex(CC0)/PubMed(公共) 可商用再分发，但**付费期刊摘要**与**下游转售授权**需法务确认；企业授权合同须写明数据来源与再分发边界。
4. **端点单一真源**：audit-closed-loops §5 建议的 `shared/endpoints.json` 已于 2026-08-17 落地：`build-site.mjs` / `unified-license/verify.js` / `unified-license/site-adapter.js` 三处统一从 `shared/endpoints.json` 读取，彻底消除三副本漂移（见 §4.5）。
5. **保持自托管推理**：P3 原则不可破，ATEX ECS 网关（`150.158.119.19:8420`）独立可用，勿为省事租第三方。

## 4. 自动化运维逻辑补强

### 4.1 现状盘点
| 自动化 | 归属 | 对 GeneTech 14站 的作用 |
|---|---|---|
| `automation-1786700735812` 每周 GEO 内容生成（周一 09:00） | ✅ 本项目 | 生成 1 篇 bio×AI GEO 文 + 更新 tracker + 尝试推送 |
| 其余 18+ 个自动化 | ❌ SwarmLabs/AIShield/RoboParts | 与本项目的数据库/商业闭环**无关** |

**诊断**：本项目只有「内容生产」自动化，**缺「健康监控」「指标沉淀」「阻塞追踪」三类运维自动化**——而这正是你最看重的「数据库有没有持续扩张」无人值守监测。

### 4.2 缺口（按严重性）
| 缺口 | 影响 | 严重度 |
|---|---|---|
| 无 DB 扩张巡检 | 游标停滞/某站归零无人知，破坏 G2 | 🔴 高 |
| 无指标沉淀 | 投资人要的护城河曲线靠人工凑 | 🟠 中 |
| 文档漂移 | audit-closed-loops L3 仍写「虎皮椒需配 notify_url」（实已证伪） | 🟠 中 |
| 端点多副本 | 三处端点数组易漂移 | 🟡 已写代码但未部署（`shared/endpoints.json` 已编，待推送，见 §4.5） |
| 巡检静默无触达 | 每日巡检仅写本地日志、无告警通道，停滞/质量红线无人知 | 🔴 高（8-18 已发生：STALL+QUALITY 未被看到） |

### 4.3 补强方案（本批落地）
1. **新增 `GeneTech 每日数据库扩张健康巡检`**（每日 06:10）
   - 读 `state/backfill-cursor.json` + 累加 22 站 `website/api/entities.json`；
   - 与 `reports/db-health/<昨日>.json` 快照比对，算增量、每站增长、检测：① 任一站实体=0（回归）；② 24h 总增量 < 50（停滞）；③ 游标未推进；
   - 写 `reports/db-health/<今日>.json` + 追加 `reports/db-health/log.md` 一行；异常输出明确告警。**不推送**（游标归 CI 所有，本地推送会覆盖扩张进度）。
2. **新增 `GeneTech 每周战略指标摘要`**（周一 09:30，接在 GEO 生成后）
   - 汇总本周实体总量/增量、GEO 文数、DB 健康趋势，产出 `reports/weekly-digest/<周一>.md`，作为投资人指标盘原材料。
3. **新增 `docs/ops-runbook.md`**：阈值定义、告警升级路径、责任人（哪些必须你本机做、哪些 AI 自动做）、手动步骤清单。
4. **修正文档漂移**：`audit-closed-loops.md` L3 删除「虎皮椒需配 notify_url」过时句（已证虎皮椒后台无此入口，回调由 worker.js 自动带）。
