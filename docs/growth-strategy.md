## 2. 竞品对比与参考（research，2026）

主流「AI 科研工具」本质都是**同一批底层索引**（Semantic Scholar / OpenAlex / PubMed）上的不同 UI：

## 9. 新借鉴的两条变现路径（2026-08-07 调研更新）

调研 2026 年一手定价后，识别出两条**对本项目契合度最高、且尚未在现有四层里充分展开**的新模式：

### 9.1 科研结构化数据授权给 AI 公司（最大护城河变现）
- **市场**：2026 科研/训练数据授权市场约 **47.4 亿美元，年增 34%**；OpenAI、Perplexity、DeepMind、Anthropic 是头部买家。
- **买方要什么**：规范化、带数据字典、可溯源（JSON-LD provenance）、API-ready 的 **JSONL / Parquet**——而非原始 PDF。
- **定价范式**：
  - 订阅授权 **$20万–500万/年**（独占域数据）；
  - 按查询 **$0.001–0.10/次**（RAG 场景）；
  - 收入分成 **3–8%**；分层独占（单一买方独占某垂直域）。
- **GeneTech 契合点**：我们已天然产出 `entities.jsonl.gz / CSV / CSL-JSON`，且**质量分 + 跨源去重 + 可溯源 URL** 正是卖点；30 个垂直域、单站 4000 条上限（理论 12 万实体）已构成「独占域语料」体量。
- **落地动作（需用户谈客户 / 走合同）**：在 `mcp.html` 与 `data.html` 加「企业数据授权」入口与询价表单；准备一份样本数据集（Parquet/JSONL + 数据字典）用于商务对接。

### 9.2 MCP 计量变现（agent-native 收费）
- **现状**：多数 MCP 免费=不赚钱。四类模型：按调用（x402 USDC 微支付）、订阅（$19–149/月）、免费增值、按结果计费。
- **结论**：廉价查询**不适合**按调用微收（50 次/天 ≈ $15/月，不值）；GeneTech 应走 **「MCP 免费发现 + Pro 订阅（HMAC 已在 api-guard 就绪） + 企业数据授权」组合**，MCP 当**分发层**而非收费层。
- **可借鉴的具体动作**：
  - 把虎皮椒 Pro 订阅与 MCP 配额绑定（api-guard 的 PRO_SECRET 已就绪，待支付网关上线即生效）；
  - 对「批量导出 / 高频调用 / 私有部署」走企业授权，而非按次 micro-pay。

### 9.3 对本项目的最终商业架构（合并旧四层 + 新两条）
```
免费层(开放数据+GEO获客) ─┐
```
