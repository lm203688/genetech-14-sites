## 0. 执行摘要

**一句话愿景**：把项目从"**给人和 Agent 查的证据图谱**"升级为"**自己持续做发现的发现网络**」——全球第一个**开放、可验证、跨域、agent 原生（Agent-Native）**的自主科学发现基础设施。市场现有玩家（Kosmos / Google Co-Scientist）全部是**封闭、单域、学者型**系统；开放+可验证+跨域+中文源这个组合位置**目前是空的**。

**为什么是现在（三个窗口同时打开）**：
1. **协议窗口**：MCP 已捐 Linux Foundation AAIF（2025-12）、A2A 加入同一治理框架（2026-08-17，250+ 成员）——Agent 互操作的标准底座刚成型，"数据/证据层"的接入标准还没人占。
2. **科学窗口**：AI 科学家系统在 2026 年集中拿到同行评审与实验验证（Nature 2026-05 两篇；Co-Scientist 已实现实验室在环操控 CVD 设备），但**幻觉/错误数量被横评为最大短板**（AutoResearch 5 次 vs AI Scientist 27 次）——"可验证性"第一次成为科学 AI 的核心竞争力而非合规负担。
3. **资产窗口**：本项目 Phase 4–7 完成了分发修复（Pagefind 30 站、实体详情页工具链、DuckDB/TEI/Splink PoC），**证据层的地基第一次铺到了能支撑上层跃迁的状态**。

**本方案核心**：**六大跃迁**——① 假设生成引擎 ② 证据强度计算（claim 级证据图）③ Agentic 自进化检索 ④ 机器可验证治理 ⑤ Agent 原生发现网络（MCP+A2A）⑥ 闭环验证（计算验证先行、实验室在环跟进）；外加贯穿全部跃迁的**诚实性层**（弃权优先 + 幻觉预算 + 发现信用账本），把它做成科学先进性的签名。

## 3. 愿景定义：自主跨域发现网络（Autonomous Cross-Domain Discovery Network, ADN）

**定义**：一个 7×24 运转的系统——它持续摄取 30 个垂直域的文献，自动完成"**证据抽取 → 跨域连接 → 假设生成 → 自动验证 → 人类/实验室复核 → 信用记账**"的完整闭环；它同时以 MCP（工具层）和 A2A（Agent 层）双协议向全球 AI Agent 开放，任何 Agent 都可以调用它的证据、提交自己的假设、认领验证任务。

**与竞品的代差定位**：

| 维度 | Kosmos / Co-Scientist | OpenAlex / S2 | **ADN（本项目目标形态）** |
|---|---|---|---|
| 开放性 | 封闭（Edison 商业产品 / Google 内部） | 开放但只到元数据 | **开放到证据与假设层，可复现** |
| 可验证性 | 报告内溯源 | 引用链接 | **claim 级证据图 + 立场 + 机器可验证签名** |
| 域覆盖 | 单域（化学/生物医学为主） | 全域但无加工 | **30 域加工 + 中文源/中医药等独占域** |
| 自主性 | 单次运行型 agent | 无 | **持续运转的网络 + 外部 Agent 协同发现** |
| 诚实性 | 幻觉横评 5–27 次/系统 | N/A | **弃权优先 + 幻觉预算 + 信用账本（签名特性）** |
| 分发 | 自有产品 | API | **MCP + A2A 双协议，agent 原生** |

**架构三层**：
- **L1 证据层**（已有资产升级）：实体 + 引用边 + claim 级证据图 + 证据强度分；
- **L2 发现层**（新建）：假设生成引擎 + Agentic 检索 + critic/自审；
- **L3 网络层**（新建）：MCP/A2A 双协议网关 + 发现信用账本 + 验证者注册（计算验证先行，实验室在环跟进）。

## 4. 六大跃迁方案（每个含：目标 / 开源技术栈 / 验收指标）

### 跃迁 1：假设生成引擎（Hypothesis Engine）——最具原创性的一跃

- **目标**：系统持续产出"**可证伪的跨域假设卡片**"。范式 = Swanson 式开放发现（LBD）× LLM 生成 × 知识图连接。输入：跨站共现/引用缺口（现有 `citation_gaps` 已有 140 个零引用对，`agent-ecosystem/orchestrator` 已有 101 个跨域对）；输出：结构化假设卡（前提实体 A + 桥接实体 B + 预测关系 + 置信度 + 证伪条件 + 引用证据链）。
- **技术栈（全开源）**：LBD 连接生成（自研在现有 KG 上加，边类型已备好）→ **DSPy** 模块化假设生成与 **GEPA** 自动优化 prompt → 本地 **Qwen3-8B/32B + vLLM** 自托管推理（成本可控）→ 假设去重与新颖度评分（与 KG 中已有路径比对 novelty）。
- **验收**：30 域各产出 ≥10 条/周假设卡；人工抽评"有价值/可证伪"比例 ≥30%（公开披露方法论，参照 HeurekaBench 的自建 harness）；与"HeurekaBench 式"harness 对标公布。
- **市场代差**：Kosmos 做单域深度，本项目做**跨域广度 + 完全开放**；Google 不做的事（不会开放假设生成 API），本项目通过 MCP 开放。

### 跃迁 2：证据强度计算（Evidence Engine）——把"可溯源"升级为"可判决"

- **目标**：对任一科学主张，输出"**证据判决**"：支持/反对/不足，附证据强度分。范式对标 **AskChem**（claim 级证据图，专家审计边类型精度 97.9%）与 Scite 的引用陈述，但做得更深：立场 × 来源等级 × 时效 × 矛盾检测 × 样本规模元数据的加权。
- **技术栈**：claim 抽取用本地小模型（**Qwen3-4B / bge-m3 检索 + LLM 抽取**，`distilabel` 做离线批量标注管线）；立场/证据分类替代现有词典（**SciCite BERT 类小模型**，PoC 报告已识别此路径）；矛盾检测 = 跨立场的共同 claim 对聚类；**DuckDB**（PoC 已完成）承载证据图查询。
- **验收**：claim 覆盖率从 0 → 核心 5 域 10 万条 claim；立场三分类 F1 ≥0.8（SciCite 基线对标）；人工审计边类型精度 ≥95%；MCP 新工具 `grade_claim`（输入主张→输出判决+证据链）。
- **市场代差**：Scite 停在 citation statement；本项目做 **claim→证据→判决** 全链，且矛盾检测为 Scite 所无。

### 跃迁 3：Agentic 自进化检索（Retrieval Engine）——直接对准 Recall@10=0.41 的塌方

- **目标**：从 BM25+RRF 升级为 **混合检索 + 多跳检索 agent + DSPy 自优化**；当前实测基线 Recall@10=0.4126、tags-inverse 类 0.065（10-14 报告）。
- **技术栈**：**bge-m3 + HuggingFace TEI** 自托管（PoC 已给路径：TF-IDF→dense 语义召回 +30–50%）+ **mxbai-rerank 重排** + **DSPy** 编译多跳检索程序（用 eval 基准 300 条做自动 prompt 优化）+ **GraphRAG** 式社区摘要（KG 已备 99,725 节点）辅助跨域查询。
- **验收**：Recall@10 ≥0.70（全量 30 站）；tags-inverse 类 ≥0.40；检索 agent 上线为 MCP 工具 `research(topic)`：自主多跳检索→证据汇总→带引用返回（**开源版 Deep Research**）。
- **市场代差**：Elicit/Consensus 的检索是封闭 SaaS；本项目把同等级能力以 MCP 工具开放，任何 Agent 免配置调用。

### 跃迁 4：机器可验证治理（Verifiable Governance）——诚实性的基础设施化

- **目标**：把"可信"从文字承诺变成**密码学可验证**：数据集版本内容哈希 + 假设卡签名 + 证据链可独立复算。这是对"AI 幻觉横评"痛点最彻底的回答——**别人报告幻觉次数，我们让第三方能复算每一条证据**。
- **技术栈**：数据集快照内容寻址（复用仓库现有 CAS 实践，DVC 做数据集版本化）+ **RO-Crate** 导出（科研打包标准）+ claim/假设卡 **RFC 3161 风格签名链**（ed25519 自签即可起步）+ 已落地的 Logpush→R2 Object Lock 10 年审计。
- **验收**：任一对外数字/假设卡可在 5 分钟内被第三方独立复算验证；发布 `VERIFY.md` 教第三方验证；治理事件 100% 有不可改审计记录。
- **市场代差**：OpenAlex/Kosmos 均无"可独立复算"承诺；这是对评审、对监管、对 Agent 消费者三重信任资产。

### 跃迁 5：Agent 原生发现网络（Discovery Network）——协议窗口的占位

- **目标**：把系统从"被查询的数据源"变成"**发现网络的协议节点**"：外部 Kosmos/Co-Scientist 类 Agent 通过 MCP 调用我们的证据与假设；我们的发现 Agent 通过 A2A 与外部 Agent 互认任务；建立"**验证者网络**"——外部实验室/计算节点用 A2A 认领假设卡验证任务，结果回流传信用。
- **技术栈**：MCP 升级到 **2026-07-28 规范**（当前仍 2025-11-25，需补 per-request `_meta` envelope——10-13 报告 N1 的如实化处理已做一半）+ **A2A Agent Card** 发布（AAIF 治理内）+ 上架 Smithery/Glama official registries + **Lago** 式按调用计量（接现有 gtk_ key 体系）。
- **验收**：上架 3 个官方 registry；MCP 规范对齐 2026-07-28；≥3 个外部 Agent 完成一次真实调用（含一个非本人 Agent）；"cited-by-agent" 遥测上线（被哪些 Agent 引用过，反哺信用账本）。
- **市场代差**：全市场没有"发现网络协议节点"这个品类；先发者定义接口（例：`hypothesize` / `grade_claim` / `verify` 三个工具名）。

### 跃迁 6：闭环验证（Verification Loop）——从假设到判决的最后一公里

- **目标**：分两步走，**先计算验证、后实验室在环**（对标 Co-Scientist 的 CVD 操控，但走开放路线）。
  - **第一步（计算验证，0 依赖）**：可重算的假设自动验证——对每条假设卡，系统自动检索"是否有新文献/数据直接检验它"（Popper 式证伪检索），输出"已证伪/待检验/获新支持"状态；与 KG 更新联动。
  - **第二步（实验室在环，合作制）**：在 2–3 个旗舰域（建议 **semiconductor 材料 / synbio-manufacturing**——与 Co-Scientist 已占的生物医学错位）签约实验室/自研计算实验（已有数据管道支撑 in-silico 筛选），验证结果作为最高等级证据回写。
- **验收**：假设卡 100% 有验证状态字段；证伪检索周报（每周自动公示"本周被系统证伪/支持的假设数"——**这是全世界没有机构发布过的指标**）；旗舰域各完成 ≥1 个真实闭环案例并公开全过程。

## 5. 诚实性层（Honesty Layer）——贯穿六大跃迁的签名设计

2026-09 五系统横评给出的行业痛点是"AI 会做研究，难的是让它承认自己错了"。本项目把已有的诚实文化升级为架构级能力，作为对全部竞品的差异化签名：

1. **弃权优先（Abstention-First）**：所有生成型输出（假设卡、证据判决、研究综述）必须带 `confidence` 与 `insufficient_evidence` 分支——置信度低于阈值时，系统输出"我不知道 + 缺什么证据"而非编造。MCP 工具在结构化输出中保留该字段（响应 schema 落 `openapi.yaml`）。
2. **幻觉预算（Hallucination Budget）**：参照横评方法，自建"错误事件台账"——每次自动发现任务记录其 hallucination/error 事件数，随 leaderboard 公开。**目标：把横评里别人 5–27 的数字，变成我们有账可查、逐月下降的曲线。**
3. **发现信用账本（Discovery Ledger）**：假设卡 → 验证状态 → 贡献者的不可改账本（Logpush→R2 已就绪）。系统发布的每个"发现"都附带可复算的证据链；被证伪同样记录（**证伪是信用，不是失败**）。这是 Agent 经济里的"信用抵押物"。
4. **指标诚实**：延续 eval leaderboard 方法论披露的做法——所有对外指标（Recall、假设命中率）必须附基准构造方式与局限说明，违者由 `guards/domain-claim-guard` 拦截（现有 guard 已覆盖此机制）。
