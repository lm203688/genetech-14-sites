### 3.1 数据质量（10 站 × 10,000 = 100,000 实体，随机 seed=7）

| 指标 | 实测 | 站点极差 | 判读 |
|---|---|---|---|
| 摘要完整度 | **74.0%** | neuromorphic **42.4%** ↔ ai-safety 88.5% | 最低站不到一半，RAG 可用性不成立 |
| 有标签率 | **68.4%** | neuromorphic **25.9%** ↔ ai-safety 88.5% | 标签决定图谱边密度，26% = 图谱在该站近乎空转 |
| DOI 覆盖 | **91.4%** | alien-minerals 75.5%、ai-safety 76.1% ↔ neuromorphic 100% | 核心卖点是"每条带 DOI"，但**接近 1/10 没有 DOI** |
| URL 覆盖 | **100.0%** | — | ✅ 唯一完全达标字段 |
| 站内重名 | **0.0%**（严格口径） | — | 见 §1 口径说明 |

> ⚠️ **勘误（2026-10-08 15:10）**：上表「站内重名 0.0%」**是错的，请勿引用**。0.0% 是因为取字段用错了名（`e.title` vs 实际字段 `e.name`），不是真的没有重名。本轮已把度量拆成三个互不替代的指标，实测值见 §9.1。

**来源分布**：crossref 42,908 / openalex 14,188 / europepmc 12,609 / datacite 10,002 / pubmed 7,936 / arxiv 6,800 / preprints 5,476 / semanticscholar **81**。
→ **前 4 源占 79.7%**，semanticscholar 近乎未接入（81 条）；datacite 占 10% 而它正是摘要/质量最差的源之一。

### 3.2 `confidence` 是伪信号（N3，本轮最重要的质量发现）

六站全量交叉统计，`confidence` 与 `source` **完全一一对应**：

```
crossref   → 0.70      openalex → 0.72      arxiv      → 0.78
europepmc  → 0.80      pubmed   → 0.82      datacite   → 0.66
preprints  → 0.74
```

**含义**：`confidence` 字段是 `source` 的 one-hot 编码，**信息量为零**（知道 source 就能推出 confidence）。它不反映摘要是否完整、领域是否相关、被引多少、是否重复。

这比 v1 描述的"两值常量"**更具欺骗性**：现在它有 7 个档位，看起来像质量分，但同一站内所有 crossref 实体分值是同一个数。对外口号"每条带 confidence"在第三方复核时会被一眼看穿。

### 3.3 知识图谱：有图无引用（v1 结论本轮确认并量化）

```
data/knowledge-graph.json:  14,356 节点 / 71,857 边
  边类型: shared_tag 38,930 (54.2%) | cross_site 29,927 (41.7%) | co_topic 3,000 (4.2%)
  引用边: 0  ← 而 data/citation-edges.json 里有 28,001 条真实引用边，线上端点也已暴露
```

**两套关系数据没有合并**。后果：`graph_search` 工具返回的是"这两个实体打了同一个标签"，而不是"这篇引用了那篇"——前者对科研用户几乎没有价值，而引用关系才是科研知识图谱的核心资产。

### 3.4 站点可达性（新增 DNS 层检测）

```
GitHub Pages  30/30 → 200 ✅
*.swarmlabs.tools (站点域) → NXDOMAIN ❌
api.swarmlabs.tools / data.swarmlabs.tools → 正常解析 ✅
```

30 个站点的自定义域**从未配置过 DNS**。对外材料若写"30 站上线 `xxx.swarmlabs.tools`"，是一个可被任何人 10 秒证伪的说法。

### 3.5 MCP Server 协议线（N1）

```
依赖: @modelcontextprotocol/sdk ^1.12.0 → lock 解析为 1.30.0（v1 线）
工具: index.mjs 中 10 处 server.tool() 注册，4 个源文件（index / graphrag / mcp-request / search）
```

而 **MCP 2026-07-28 规范**已于 2026-07-28 正式发布，是协议诞生以来最大重构：

- **SEP-2575 / SEP-2567**：移除 `initialize` 握手与 `Mcp-Session-Id`，核心转**无状态**；`protocolVersion`/`capabilities` 改走每次请求的 `_meta`
- **SEP-2243**：Streamable HTTP 强制 `Mcp-Method` / `Mcp-Name` 头，头体不一致必须拒绝
- **SEP-2260 / SEP-2322**：取消长连接 SSE 推送，交互改 `InputRequiredResult` 多轮往返
- **SEP-2164**：资源未找到错误码 `-32002` → `-32602`
- **SEP-2577**：Roots / Sampling / Logging **废弃**（12 个月移除窗口）
- 官方 TypeScript SDK 已切 **v2 稳定线**，包名改为 `@modelcontextprotocol/server` / `@modelcontextprotocol/client`

**判读**：v1 SDK 服务器在 2026-07-28 后**仍能工作**（生命周期策略保证 ≥12 个月），但生态判据已经变了——**客户端兼容矩阵、Claude 连接器目录审核、各 Registry 都会以新规范为门槛**。一个尚未发布的产品，没有理由发布在旧协议线上。

### 5.2 国内政策窗口（本轮新增）

2026 年国家数据局"数据要素×"持续推进，**可信数据空间试点扩容**、**企业数据资产入表**已有明确操作路径（合规确权 → 成本归集 → 入表）。对本项目的意义：
- "可溯源数据资产"在国内有**合规变现与资产化通道**，不只是卖给 AI 实验室一条路；
- 建议把"数据资产入表 / 交易所挂牌"作为 E5 的落地抓手，而非泛泛的"对接合规"。

### 5.3 竞品定位

| 竞品 | 定位 | 我们的差异 | 差距 |
|---|---|---|---|
| OpenAlex / Crossref / PubMed | 免费学术元数据底座 | 我们做**跨源归一 + 跨域桥接 + 缺口发现** | 它们是源，我们是加工层——**加工深度尚未被证明**（§3.2） |
| Elicit / Consensus / Scite | 人读的 AI 文献工具，英文订阅制 | 我们**机器可调用 + 人民币买断 + 中文域** | 它们有产品完成度与付费用户；我们只有 API |

**结构性机会**：国内"Agent 原生 + 垂直科研 + 人民币买断 + 可溯源"仍是供给真空。但真空 ≠ 需求，**必须先证明有人愿意付钱**。

## 9. 实施后实测与勘误（2026-10-08 15:10，本轮实施轮）

> 本节目的不是补充成绩，而是**让报告与代码库现状一致**。§3.1 与 §6-A6 两处结论已被实测推翻，此处留痕。所有数字由 `node operations-plan/pipeline-quality-gate.js` 一键复现，产物在 `reports/quality-metrics-2026-10-08.json`。

### 9.1 「重名率」是一个虚构的问题（最重要的勘误）

本报告 v2 写的「站内重名 0.0%（严格口径）」**是错的**，`quality.policy.json` v1 用的「重名率 10.9%」也是错的。两个错误方向相反，结论却都成立：**重名率不该被当成质量指标，更不该用来压容量**。

| 指标 | 定义 | 全 30 站实测 | 是否拦门禁 |
|---|---|---:|---|
| `duplicate_rate` 真重复 | `dedupeKey` 重复。有 DOI 用 `doi:<doi>`，无 DOI 用 `t:<规范标题>#<排序作者>` | **0.00%**（仅 carbon-neutral 2 条） | ✅ 阈值 0.01 |
| `title_collision_rate` 同名碰撞 | 同标题不同 DOI/作者，是**不同文献** | 9.12% | ❌ 仅诊断 |
| `boilerplate_rate` 前置页噪声 | 标题命中泛化词表 AND 无摘要 AND 无标签 | 清理前 1.89% → **0.00%** | ✅ 阈值 0.05 |

**关键取证**（这些数字决定了结论）：

- brain-science 重名 16.6% 的最大组是 `Editorial Board` × 394，全部来自 crossref，**DOI 各不相同**、零摘要零标签 → 是 394 篇不同的编辑部成员列表文章，不是 1 篇被灌了 394 次。
- 分类统计：brain-science 冗余 1,617 条中**同 DOI 真重复仅 3.3%**，不同 DOI 同名占 96.7%；exo-science 89.3%、privacy-computing 97.2%。
- `vantage6` × 140 有 140 个不同 DOI 且**全部带摘要** → 真实记录，绝不能删。

**后果**：`deny-high-duplicate`（旧阈值 0.12，v1 口径）一直在为不存在的理由，把 brain-science / edge-ai / exo-science 压到 10,000 容量。**真正的杠杆不是去重，是修正度量本身。**

⛔ 因此 §6 的 **A6「来源结构优化 / 跨源归一」作为治重名手段作废**——真重复只占重名冗余的 3.3%，跨源 dedupeKey 归一最多解决 3.3%，剩余 96.7% 是"世界上的论文确实同名"，任何归一逻辑都不该合并它们。A6 剩余的有效部分（降 datacite、接 semanticscholar）仍是有效建议，但优先级低于 A5。

### 9.2 前置页噪声是独立的内容质量问题（已治理）

判据三重与，后两条是**安全护栏，缺一即保留**：

```
isBoilerplate(e) = 标题 ∈ BOILERPLATE_TITLES(约 90 个泛化标题)
                AND 摘要为空
                AND 标签为空
```

护栏存在的原因：`vantage6` × 140、`mh370: mathematical proof...` × 95 这类记录标题虽短但**带摘要**，是真实出版物，必须留下。三重与把误删率压到 0。

| | 清理前 | 清理后 |
|---|---:|---:|
| 实体总数 | 300,000 | **294,330**（清除 5,670） |
| 前置页噪声 | 1.89% | **0.00%** |
| 摘要完整度 | 67.7% | **69.0%** |
| 有标签率 | 63.5% | **64.7%** |
