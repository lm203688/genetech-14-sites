## 0. 执行摘要（一页结论）

**一句话**：项目已建成一座**结构完整、可对外服务**的知识基础设施（30 站 / 300,000 实体 / 11 MCP 工具 / 9+ 端点在线 / 治理与门禁体系成型），但**三件事同时停摆**——**数据飞轮自 2026-09-01 起冻结 37 天**、**支付闭环未部署（线上实测仍返回 `not_found`）**、**商业收入为零**——使其停留在"能演示的资产"而非"能增长的产品"。

**四个必须先解的问题（P0，按 ROI 排序）**

| # | 问题 | 硬证据 | 为什么致命 |
|---|---|---|---|
| 1 | **飞轮被容量策略冻结** | 30 站 `index.json` 全部 = 10,000（= `guards/publish.policy.json` 的 `site_capacity` 上限）；`lastUpdated` 全部停在 2026-08-31 ~ 09-01；git log 连续 `[Bot] Data backfill update (+0 entities)` | 唯一护城河"数据持续扩张"已停 37 天，且是**自伤**（策略封顶，非源耗尽） |

## 4. 关键发现（按严重度，均附证据）

### 4.1 🔴 P0 — 飞轮被自己的容量策略冻结（自伤，非外部原因）

```
guards/publish.policy.json:
  site_capacity: { 全部 30 站: 10000 }
  allow-normal-batch 要求 total_after <= site_capacity

实测：30/30 站 totalEntities = 10000，lastUpdated 停在 2026-08-31 ~ 09-01
     git log: [Bot] Data backfill update (+0 entities) × 连续多轮
```

护城河指标"实体增长曲线"已经是一条水平线 37 天。更麻烦的是：**README 与对外材料仍在宣称"数据飞轮持续扩张"**——这是对外口径与实际状态的偏离，评审或尽调一旦核对 `lastUpdated` 就会穿帮。

### 4.2 🔴 P0 — 支付修复"已编码 + 过 CI + 未部署"

线上实测 `not_found`，而修复版应返回 `202 unknown / 请勿重复下单`。仓库里 `unified-license/worker.js`（38KB，10-05 更新）、`_test_pay_states.mjs`（5 项）、`_test_pay_retry.mjs`（4 项）都已就位。**唯一阻塞是 `wrangler deploy` 需浏览器 OAuth**。

这类"代码写完就算完成"的模式在本项目反复出现（v1.1 报告已自纠过一次：DOI 捕获"已编码未部署"）。它不是一个技术债，是一个**流程病**：交付判据应从"代码合并"改成"线上实测返回值"。

### 4.3 🟠 P0 — 数据质量三处硬伤（抽样 80,000 实体）

| 指标 | 实测 | 站点间极差 | 影响 |
|---|---|---|---|
| 摘要完整度 | **62.7%** | tcm-tools 41.0% ↔ embodied-ai 86.7% | 直接决定 RAG 可用性；低于 README 宣称的 66.2% |
| 有标签率 | **62.7%** | semiconductor 43.5% ↔ embodied-ai 83.8% | 标签决定图谱边与跨域桥接，缺标签 = 图谱稀疏 |
| 站内重名率 | **10.9%** | 910 ~ 1,188 条/站 | 同站同标题不同 DOI（预印本/正式版/多源重复），对外计数虚高 |
| `confidence` 分布 | **仅 {0.7: 64.7%, 0.8: 35.3%}** | 全站一致 | **伪信号**——对外宣称"每条带 confidence"，实际是一个两值常量，不承载任何质量语义 |
| 分片索引覆盖 | **76.0%**（库 260,689 DOI / 分片 198,114） | — | 24.0% 实体**搜不到**；对外"覆盖率 100%"说的是"片内 100% 带 DOI_or_URL"，语义被误读 |
| URL 溯源 | 100% | — | ✅ 唯一完全达标的字段 |

**领域错配实例（实测抽样，非推断）**
- `new-energy` 站内出现 **"The Dark Energy Survey" / "Large Synoptic Survey Telescope: Dark Energy Science Collaboration"** —— 天文学的 *dark energy（暗能量）* 被当成 *new energy（新能源）* 收录。
- `semiconductor` 站内 arxiv 源出现 **"The application of collagen in advanced wound dressings"**（胶原伤口敷料）。
- `tcm-tools` 站内出现 **"Efficacy and safety of quadruple therapy versus triple therapy in patients with heart failure"**（心衰疗法，与中医药工具无关）。
- `datacite` 源存在成对完全同名条目（"An Ab-initio Study of…" ×2、"Traditional Herbal Medicine in Supportive Cancer Care" ×2）。

> **结论**：P4 原则"垂直做深不做浅"目前**没有被任何指标度量、没有被任何门禁拦截**。"做深"是口号，不是被验证的属性。这是本项目对外叙事里**最脆弱的一环**。

### 4.4 🟠 P1 — 知识图谱"有边无引用"

14,355 节点 / 71,857 边，但**边 100% 是标签共现与跨域桥接，0 条引用边**。而 `data/citation-edges.json` 里已经有 27,340 条真实引用边——**两套关系数据没有合并**。结果：`graph_search` 工具返回的是"这两个实体打了同样的标签"，而不是"这篇引用了那篇"。前者对科研几乎没有价值。

### 4.5 🟠 P1 — 语义检索是 token 匹配，不是向量检索

`search-index.json` 6.58MB / 13k 高置信实体 token 匹配。2026 年 RAG 基线已是"向量 + 图 + 重排"三段式。**当前方案在召回质量上落后一代**，且分片覆盖只有 76%。

### 4.6 🟡 P1 — 编排与可观测"刚落地、未接产"

`orchestrator.mjs` 产出 101 项可放行决策、`observe.mjs` 采集 8 层状态——但两者都是**一次性手工运行结果**，未进 CI、未产生告警触达。`observe.mjs` 自己报告 `pipeline: {scanned:68, ok:0, fail:0}`（全零），说明它也还没真正解析出管线结论。

### 4.7 🟡 P2 — 安全与文档治理

- 历史 secret 泄漏（`ghp_` / `cfut_` / 虎皮椒 / `CORE_API_KEY`）自 2026-08 挂到现在未清。
- `docs/` 目录下 ALERT-*.md、audit-*.md、competitor-models.md、growth-strategy.md 与对外文档同目录，而仓库是**公开仓**。已有"白名单 4 份"的约定，但目录结构本身不构成保护。
- AOCI code 索引 520 条待写（认知层只跑了 baseline，未 maintain）。

## 5. 国际市场与竞品对标（2026）

### 5.1 训练数据 / 内容许可市场：provenance 从"加分项"变成"准入项"

| 事实（2026） | 数字 | 对本项目的含义 |
|---|---|---|
| 全球 AI 训练数据集市场 | **$163 亿 / 2033**，2026 起 CAGR **22.6%**（Grand View Research） | TAM 成立 |
| 高质量公开文本存量 | Epoch AI 预测 **2026–2032 年间被耗尽** | 公开数据稀缺 → **有溯源的非公开/结构化数据溢价** |
| Thomson Reuters v. Ross（2025-02） | 首个否定 AI 训练**公平使用**抗辩的重大判决 |  buyers 必须证明"获取合法" |
| Anthropic 作者和解（2026-07 终审） | **$15 亿**，约 **$3,000/本** × ~50 万部 | 责任集中在**获取方式**而非训练行为 → **provenance 成为采购刚需** |
| 学术内容许可成交 | **Wiley × 多家 AI 实验室**（2024–2025）；**Taylor & Francis × Microsoft $10M+**（2024） | ⭐ **学术数据授权有真实、公开的成交先例**——正是本项目要卖的东西 |
| 双边 vs 市场单价 | 双边协议的隐含单条引用价是市场价的 **2–10×**（Presenc AI, 2026-04） | 别只做自助买断，**要做 BD** |
| 2026 交易结构惯例 | 2–5 年期；**训练权 + 实时 feed 打包**；**归因要求**条款化 | 我们的 API/MCP 就是"实时 feed"，应与训练权打包谈 |

**判读**：项目把"每条可溯源"当成道德优势，其实它是**可以直接标价的资产属性**。差距在于——市场上没有任何一份材料告诉买家"我这里有 27.7 万个唯一 DOI、覆盖 30 个前沿科技域、每条带来源与抓取时间、可按域切片授权"。

### 5.2 竞品定位

| 竞品 | 定位 | 我们的差异 | 差距 |
|---|---|---|---|
| **OpenAlex / Crossref / PubMed** | 免费学术元数据底座 | 我们做**跨源归一 + 跨域桥接 + 缺口发现** | 它们是**源**，我们是**加工层**——但加工深度尚未被证明（§4.3） |
| **Elicit / Consensus / Scite** | 人读的 AI 文献工具，英文为主，月订阅 | 我们**机器可调用 + 人民币买断 + 中文域** | 它们有产品完成度和付费用户；我们只有 API |
| **Scite（2026 初发 MCP Server）** | 引用立场分析 | 印证"知识底座 MCP 化"方向正确 | 我们 MCP 已就绪但**未发布**，眼看着窗口被占 |
| **Perplexity / 秘塔** | 答案引擎 | 我们不做答案，做**可审计的语料层** | 它们已被 AI 大量引用（GEO 见效）；我们无引述率实测 |
| **Schrödinger / 晶泰** | 卖水人（软件授权 74% 毛利 / 平台+里程碑） | 模式对齐 | 它们有复购率 75%+ 与真实合同 |
| **Recursion** | 自有管线赌单药（净亏 $6.45 亿，NVIDIA 退出） | ❌ 明确不抄 | — |

**结构性机会**：国内"Agent 原生 + 垂直科研 + 人民币买断 + 可溯源"仍是**供给真空**。但真空不等于需求——**必须先证明有人愿意付钱**（§7-E）。

### 5.3 技术趋势对标（2026）

| 趋势 | 2026 状态 | 本项目 | 缺口 |
|---|---|---|---|
| **MCP 协议** | 事实标准；官方 Registry + Glama（71k servers）+ Smithery 覆盖；生态从"能用"到"可规模化部署" | 自研 server v1.2.0，11 工具 | 未上架任何 registry；无 remote/HTTP MCP 端点 |
| **远程 MCP** | 2026 主流转向 Streamable HTTP / 托管端点，`npx` 本地只是入门 | 仅本地 stdio | 企业买家要的是 URL + key，不是 npx |
| **GraphRAG** | 2026 已是"图 + 向量 + Agentic 路由"三代融合；与 Naive RAG 准确率差距可达 3.4× | 有图、有 token 检索，无向量、无融合 | 检索能力落后一代 |
| **Agent Memory** | mem0 / Letta / Graphiti 成熟 | AOCI（仓库级认知） | 缺会话级/实体级记忆；但对本项目非瓶颈 |
