# 引用立场抽取报告（T5.1 · 最小可用）· 2026-10-18

> 对应 SCI 达标提升方案 §T5.1。本文件记录 GeneTech 引用立场抽取（support / contrast / mention）
> 的最小可用实现与诚实边界，作为 Data Descriptor 论文方法节的实证。

## 1. 方法与诚实边界（必须先读）

- **数据现实**：本数据集 `data/citation-edges.json` 仅存
  `(citing, cited, fromSite, toSite, method, tier)`，**未保留引用句(citation context sentence)**。
  因此**严格的句级引用立场分类在本数据集上不可直接执行**。
- **最小可用方案（摘要级代理）**：以「引用方论文的摘要(abstract)」作为上下文代理，以
  「被引方论文的标题/标签词」作为被引主题 token，用 support/contrast/mention 词典（中英）
  判定立场。不依赖大模型。
- **这是代理而非句级上下文**，论文必须如实说明：摘要级代理只能覆盖「被引主题出现在摘要中」
  的边，其余边标记为 `unknown`（仅列于参考文献，无法从摘要判断立场）。
- **真值 P/R**：需人工在 200 条样本上标注 `goldStance`；标注后重跑即可计算 P/R 与一致性。
  当前 `goldStance` 字段留空，故**报告 P/R 待人工标注完成**（标注者动作）。

## 2. 模块自测（词典方向正确性）

手工构造 6 句（3 support / 3 contrast），`--self-test` 结果 **6/6 通过**，证明词典
support/contrast 方向正确、优先级（contrast > support > mention）合理。

## 3. 量化结果（抽样 200 条，种子随机）

| 指标 | 值 |
|---|---|
| citation-edges 总数 | 25,682 |
| 可分析边（双方可解析 + citing 有摘要） | 9,624（**37.5%** 覆盖） |
| 抽样样本数 | 200 |
| 预测 stance=contrast | 44 |
| 预测 stance=support | 25 |
| 预测 stance=mention | 6 |
| 预测 stance=unknown（被引主题未出现在摘要） | 125 |

## 4. 诚实解读（论文必须保留）

- **37.5% 覆盖率**来自两层限制：① 引用方论文约 30% 为 abstract 存根（stub，无摘要）；
  ② 即便有摘要，被引主题词未必出现在摘要（很多引用仅列于参考文献）。这两点都是数据层的
  真实约束，不是分类器缺陷。
- **62.5% 的边无法在摘要级判定立场**——要提升需在未来数据收集中**保留引用句(snippet)**，
  这是明确的未来工作（论文"局限与路线图"节）。
- **汇报的 P/R 不是 100% 自证**：当前只给出预测分布与覆盖率；真正的 precision/recall 需要
  人工标注 `goldStance`（已预留字段）。我们不臆造精度数字。
