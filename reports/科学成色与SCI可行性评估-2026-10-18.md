# GeneTech 30 站知识引擎 · 科学成色与 SCI 可行性评估

> 评估日期：2026-10-18
> 角度：科学性（scientific rigor）+ 可否写成 SCI 论文
> 方法：实测数据产物 + 评测台 + 白皮书 + 文献对标（WebSearch 子代理）
> 结论先行：**数据底座和工程治理达到 SCI 级，但"科学发现"内核未经任何人类/金标准验证，核心方法已被 SOTA 覆盖，评测仅覆盖 3/30 站——直接以"发现引擎"投 AI/科学发现顶会不可行；改走"可验证数据集 + 资源论文"路线则现实可行。**

---

## 一、科学性三层拆解（核心判断）

把这个项目拆成三层，科学成色完全不同：

| 层 | 内容 | 科学成色 | 关键证据 |
|---|---|---|---|
| **A. 数据/基础设施层** | 30 域、294,330 实体、DOI/PMID 溯源、identity-map 别名表、签名溯源、可复算 | **强** | identity-map.json 108MB、KG v5 双时间戳、ed25519 签名校验 |
| **B. 方法层** | LBD 跨域桥接、引用缺口、claim 抽取、honesty/弃权 | **中偏低** | 方法均为 Swanson/Arrowsmith/MOLIERE 的规模化重实现，无方法学新颖性 |
| **C. 科学贡献层** | 1,062 张"可证伪"假设卡 | **弱（未验证）** | 0 人类评估、0 金标准评测、0 实验/历史回溯验证 |

**一句话**：这是一个"工程上很诚实、科学上未闭环"的项目。它的诚实（白皮书自承 stub 58%、仅覆盖 76% DOI、3 项外部硬阻塞）反而是加分项，但科学贡献的"证伪/验证"只停留在 JSON schema，没有落到真实世界。

## 二、亮点（若写论文，这是能讲的故事）

1. **可验证治理（provable provenance）**：所有对外数字带来源、签名可验、可第三方复算——这是相对 OpenAlex/Semantic Scholar 的差异化点，且是架构级能力（`tools/ci-verify-sig.mjs`、9/9 签名一致）。属于**工程/治理贡献**。
2. **30 域跨域空白矩阵**：870 有向域对、140 零引用域对（`data/claims.json`）。思路成立，是科学计量分析的天然素材。
3. **假设卡结构规范**：每张卡含 `falsifiability`（含 falsification_condition + test + time_horizon）、`evidence_requirement`、`verification_plan`、`provenance`——结构本身达到方法论文档标准（`data/hypothesis-cards.json`，1,062 张，schemaVersion 化）。
4. **评测台存在且方法论自省**：`eval/run-eval.mjs` 计算 Recall@K/MRR/NDCG@K，且明确标注**"benchmark v1 的 100% Recall 是 query 抄答案的恒等式，已废弃"**——这种自我批判在学术写作里是加分的。

## 三、致命弱点（阻塞 SCI 发表）

按严重度：

- **W1（致命）假设无任何人类验证**。1,062 张"可证伪"假设，0 位领域专家评估、0 实验验证、0 历史回溯验证。Swanson 方法要求"经实验验证方成新知识"。最可比工作 Gu & Krenn (arXiv 2405.17044, 2024) 用了 **100 位研究组组长**做人类评估——本项目缺这一环，无法证明假设"有趣/新颖/可行"。
- **W2（致命）无 baseline、无 gold-standard 评测**。假设/证据/空白检测全无金标准集；"零引用缺口"未与 OpenAlex 引用网对照，白皮书自己承认"零引用可能是没抓到"。
- **W3（致命）核心科学能力被自身文档证伪**：README 自承"跨源实体解析 ❌、引用立场抽取 ❌、向量 RAG ❌、跨源归一 ❌"。投稿时审稿人会要求展示这些，而项目自述"知识侧尚未开工"。
- **W4（严重）评测仅覆盖 3/30 站**。留存结果 `eval/results-2026-10-14.json` 显示 `sites#: 3, queryCount: 30`，avgRecall@10 = **0.41**；按类型：`tags-inverse` 0.065、`cross-entity` 0.150、`site-topic` 0.000、`abstract-mid` 1.000——即**真实检索场景（按 tag/跨实体）基本失效**，只有"摘要中段字面匹配"能召回。白皮书宣称"全量 30 站评测"与留存事实不符。
- **W5（严重）数据基座薄且可能冻结**：引用网络真实基座仅 **1,634 学术种子**（`academicSeedCount`）；实体 `updatedAt` 停滞约 45 天（飞轮冻结）。数据是快照而非可刷新流，外部效度存疑。
- **W6（中）claim 抽取是 lead-sentence 启发式**：`extracted-claims.json` 的 predicate 为 `shown/enables/limited` 等摘要首句动词，avgConfidence 0.6，非真关系抽取；abstract 缺失 30.89% 造成覆盖空洞（NLP 文献中 lead-sentence 假设已知偏差大）。
- **W7（中）随机数 confidence**：`pipeline-intelligence.js:448` 社区情报缺口用 `0.6 + Math.random()*0.3` 作 confidence——虽不落入假设卡，但任何以"confidence"示人的随机数都不科学，需改为确定性评分。
- **W8（中）数字自相矛盾**：DOI 数在 ai.txt/whitepaper/claims.json 出现 276,769 / 271,099 / 256,086 三口径；零引用对 101 vs 140；MCP 工具 11 vs 14。审稿人一见即疑数据可靠性。
- **W9（轻）弃权率 0.999 需精确定义**：`honesty-ledger.json` 显示 963 query 仅答 1，**需证明"无证据即拒"而非退化**，否则像指标游戏。

## 四、对标文献（新颖性判定）

| 方向 | SOTA | 本项目 | 新颖性 |
|---|---|---|---|
| LBD / 假设生成 | Swanson→MOLIERE→Gu&Krenn(100 专家评)→AI Scientist | 1,062 卡 | 低（规模化重实现，无人类验证） |
| 大型学术 KG | OpenAlex(2.4 亿 works)、S2、MAG、COCI | 29 万实体 | 低（规模 0.06%，跨源归一未实现） |
| 跨域空白挖掘 | Foster/Uzzi/CiteSpace/科学计量 | 870 域对、140 零引用 | 中偏低（基座薄） |
| 诚实/弃权 | SciCite/Self-RAG/RAG 事实性 | abstention 0.999 | 方法学可疑 |
| 可验证治理 | ORKG/OpenCitations 开放溯源 | 签名+可复算 | **相对最像新奇点**（但偏工程） |

**结论**：科学发现内核被更成熟系统覆盖；唯一可讲差异化是"可验证治理"这一工程贡献。

## 五、可否写 SCI —— 可行路径与最低补齐清单

### 可行（推荐定位：资源/数据论文，非发现论文）

| 投稿目标 | 合适 venue | 为什么 |
|---|---|---|
| 可验证科学证据图（数据集） | **Scientific Data / Nature Sci. Data** | 最契合"可引用数据集 + 数据描述 + 可用性声明" |
| 跨源归一 + 可复算治理 + 检索评测 | **JCDL / ISWC**（resource/demo） | 数字图书馆/语义网基础设施主场 |
| 30 域零引用矩阵做科学计量分析 | **Scientometrics / QSS / JASIST** | 把"空白矩阵"当方法论文献，而非工程系统 |
| 数据集 + baseline 检索系统 | **CIKM / ACL Findings**（资源轨） | 强调 BM25/RRF + 评测 harness |

> 务实建议：**最易中稿是 Scientific Data 或 JCDL/ISWC 的 resource/demo**，而不是把"假设生成"当科学贡献投 AI 顶会（会被 Gu&Krenn / AI Scientist 直接压过）。

### 投出前必须补齐的最低门槛（按优先级）

1. **人类专家评估假设**（P0）：抽样 50–100 张卡，3–5 位领域专家按"有趣/新颖/可行"盲评，给出 inter-rater 一致性。这是 W1 的唯一解药。
2. **与 OpenAlex 引用网对照的 baseline**（P0）：证明 140 零引用对不是"没抓到"，而是真实空白。
3. **真实跨源实体解析最小实现**（P0）：先把 W3 里"❌"的至少一项落地（引用立场抽取成本最低）。
4. **评测扩到 30 站 + 人工标注 gold subset**（P1）：消除 W4 的 3 站假象。
5. **刷新冻结数据 + 给出刷新策略**（P1）：证明是可刷新流（W5）。
6. **修随机数 confidence、统一数字口径**（P1）：消除 W7/W8 的"数据不可靠"印象。
7. **弃权率精确定义 + 在保留假设上的精度**（P2）：化解 W9。

## 六、最终裁决

- **科学成色评级**：**B-/C+**（数据底座 A-，方法层 B-，科学贡献 C+）。诚实度是亮点，验证度是死穴。
- **能不能写 SCI**：**能，但必须换定位**——从"自动科学发现引擎"转为"**一个带可验证溯源的 30 域学术知识图数据集 + 资源论文**"。当前状态直接投"发现"类顶会 = 拒稿；走 Scientific Data / JCDL / ISWC 资源轨 = 有现实机会，前提是补齐第 1–4 项。
- **一句话给老板**：楼的数据地基和"可复算"招牌够硬，但"发现"这层还没被任何人类或实验证过——别先讲"我们发现了新科学"，先讲"我们交付了一个可被第三方复算的、诚实标注缺陷的跨学科知识图"，这反而更容易发、也更经得起审稿。
